## Part E: Optional Enhancements

The following items are not required for the minimum submission but would strengthen the project.

| Enhancement | Notes |
|-------------|-------|
| Fully develop Lessons 1, 4, 5, 7, and 8 into complete lesson packs | Significant effort; not required for initial submission |
| Create print-ready PDF versions of the learner workbook | Requires a tool that converts Markdown to PDF; do not install without checking disk space |
| Create visual activity card sheets for each lesson | Paper-based; can be done as a simple formatted document |
| Add a visual curriculum overview diagram | Mermaid or ASCII diagram; no external tool required |
| Create a facilitator one-page quick reference card | One-page summary of each lesson's vocabulary and activity |
| Translate materials into plain-text for screen-reader testing | Low effort; high accessibility value |
| Record pilot data after running actual sessions | Requires real participants; do not invent data |
| Revise materials based on pilot feedback | Requires completed pilot first |
